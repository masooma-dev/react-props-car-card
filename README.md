# React Props - Car Card

A clean, reusable React component displaying car details using props.

### Features
- Displays 3 cars using reusable CarCard component
- Uses props for name, image, price, model
- Clean & responsive UI
- Built with React, JavaScript, CSS

### How to Run
npm install
npm start
